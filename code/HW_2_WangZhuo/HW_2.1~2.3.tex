\section{3.2}

We can notice that $\mathbf{w}^\top\mathbf{x}+b=\langle \mathbf{w},\mathbf{x}+\frac{b}{\langle\mathbf{w},\mathbf{w}\rangle}\mathbf{w}\rangle$ and $-\frac{b}{\langle\mathbf{w},\mathbf{w}\rangle}\mathbf{w}$ is an orthogonal vector on the plane $\mathbf{w}^\top\mathbf{x}+b=0$. 

For arbitrary vector $\mathbf{x}$, its distance from the plane is equal to 
\[|\langle \frac{\mathbf{w}}{||\mathbf{w}||},\mathbf{x}+\frac{b}{\langle\mathbf{w},\mathbf{w}\rangle}\mathbf{w}\rangle|=\frac{|\mathbf{w}^\top\mathbf{x}+b|}{||\mathbf{w}||}.\]

For given Training Set $\{x_i,y_i\}_{(n)}$
Soft Margin SVM Model:
\[
\min_{w,b}\ \frac{1}{2}\|w\|^2+C\sum_{i=1}^{n}\max\{0,1-y_i(w^\top x_i+b)\}.
\]
Hinge loss function:
\[
\ell_{\mathrm{hinge}}(z)=\max\{0,1-z\},\qquad z=y_i(w^\top x_i+b).
\]
